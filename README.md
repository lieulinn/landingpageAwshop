# landingpageAwshop# AWSHOPEDIA — Web Statis (Neo-Brutalism Style)

Web statis resmi **AWSHOPEDIA** dengan gaya estetika **Neo-Brutalism** (border tebal, hard shadows, kontras warna tinggi) yang terintegrasi dengan ekosistem **Lvara.academy**.

---

## 🛠️ Fitur & Keunggulan

- **Neo-Brutalism Design**: Karakter antarmuka visual yang tegas, kreatif, dan modern.
- **Theme Switcher**: Mode Gelap & Mode Terang dengan penyimpanan di `localStorage`.
- **Responsive Layout**: Adaptif dari layar smartphone hingga monitor resolusi tinggi.
- **Pure Native Stack**: Dibuat murni menggunakan HTML5, CSS3, dan Vanilla JavaScript tanpa *dependency* eksternal yang berat.
